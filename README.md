## 주요 기능

- **국가별 필터 & 자동 이동:** `전체 / 🇰🇷 대한민국 / 🇯🇵 일본 / 🇭🇰 홍콩 / 🇹🇼 대만` 원클릭 전환 및 지역·시/구 동적 필터링.
- **음식 종류 & 등급 필터:** 12대 카테고리(`한식`, `일식·초밥`, `중식`, `고기·구이`, `면·만두`, `해물·회`, `국밥·탕·찜`, `분식`, `양식·세계음식`, `카페·디저트`, `치킨·주점`) + `타베로그 백명점·4.0+` / `미슐랭 가이드` / `도쿄·오사카 추천` / `홍콩·대만 로컬 명소`.
- **지도 ↔ 전체 리스트 전환:** 클러스터링 지도(표준/다크/클린 맵)와 카드형 전체 리스트(가나다순·메뉴순·거리순 정렬) 자유 전환.
- **국가별 맞춤 길찾기:** 한국(네이버 지도·카카오맵·구글 지도), 일본(구글 지도·타베로그 바로가기), 홍콩·대만(구글 지도·리뷰 검색).
- **즐겨찾기 · 랜덤 추천(🎲) · 디스코드 복붙:** 필터링된 결과만 2,000자 단위 디스코드 블록으로 즉시 복사 또는 `.md` 다운로드.
