# 🍽️ 맛집 지도 & 리스트 (Matjip Map)

전국 **2,466곳** 맛집을 인터랙티브 지도에서 탐색하고, 마크다운 리스트로 바로 공유할 수 있는 오픈소스 웹 앱입니다.

- **🗺️ 라이브 지도 앱 바로 열기:** https://aetherx86.github.io/matjip-map/
- **📄 전체 마크다운 리스트 보기:** [LIST.md](LIST.md) (`식당 이름 — 무슨 음식 파는지 · 위치`, 디스코드 복붙 최적화)

## 주요 기능

- **전국 2,466곳 클러스터링 지도:** API 키 없이 바로 동작하며 한국어 지도(OSM) · 다크 맵 · 클린 맵 전환을 지원합니다.
- **초고속 실시간 검색 & 필터:** 식당명, 메뉴명, 업종, 시/구(`수원시`, `서울 강남구` 등), 12대 음식 카테고리, 현재 지도 영역 내 필터링.
- **내 주변 거리순 정렬 & 랜덤 추천(🎲):** GPS 기반 거리순 정렬과 현재 필터 내 랜덤 맛집 룰렛 기능.
- **메뉴·가격 & 원클릭 길찾기:** 식당 클릭 시 대표 메뉴·가격, 주소 복사, 네이버 지도·카카오맵·구글 지도 바로 연결.
- **즐겨찾기 & 디스코드 복붙 내보내기:** 원하는 지역/메뉴만 필터링한 뒤 2,000자 단위 디스코드 복붙 블록 복사 또는 `.md` 다운로드 지원.

## 로컬 실행

```bash
npm install
npm run dev
```
